All release figures have PDF, SVG, and 600-dpi PNG variants with source data
under `04_FIGURES/source_data` and hashes in
`04_FIGURES/figure_manifest.json`. Fig. 3 source data include the anonymized
prediction rows and the development-threshold selective-risk table.

The panel-level traceability contract is recorded in
`04_FIGURES/panel_traceability.csv`. It binds each panel group to its analysis
unit, sample scope, statistic, source data, generating script and evidence
boundary. The hash manifest verifies file integrity; the panel traceability
table supplies the scientific provenance layer.
