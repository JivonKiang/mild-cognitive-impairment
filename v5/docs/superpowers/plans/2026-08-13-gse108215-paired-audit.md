**Goal:** Add a reproducible, label-leakage-free, supplementary-only audit of the frozen partial score in the GSE108215 paired MCI intervention cohort.

**Architecture:** The new analysis reads only the official GEO series matrix and GPL570 annotation retained in the isolated run bundle. It derives a fixed 10/12 exact-symbol score before using arm or timepoint labels, then summarizes only paired subject-level changes without exporting participant identifiers. GSE153881 is documented as blocked because official metadata and supplementary filenames conflict on MCI/AD labels.

**Tech Stack:** Python 3, pandas, NumPy, SciPy, official NCBI GEO files, unittest.

```python
def parse_title(title: str) -> tuple[str, str, str]:
    match = TITLE_PATTERN.fullmatch(title.strip())
    if match is None:
        raise ValueError(f"unparseable GSE108215 title: {title}")
    return match.group("arm"), match.group("time"), match.group("subject")
```

The script must stop if any title cannot be parsed, if a paired subject has duplicate timepoints, or if the exact mapping is not 10/12 with `PHF15` and `LAT1-3TM` absent. It must use no arm/timepoint labels for probe aggregation or score standardization.
