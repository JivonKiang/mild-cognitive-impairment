# Citation

Please cite this repository when reusing its code, analysis workflow or
aggregate result tables. Please also cite the associated scientific article
when its final bibliographic record and DOI are available.

## Current repository citation

Use the author list and metadata in `CITATION.cff`:

> Jiang, F., Wang, S., Li, M., Dou, X., Gong, L., Sun, Z., Lu, N., and Dong,
> J. (2026). *Mild cognitive impairment: public blood transcriptomics*
> [Computer software]. GitHub.
> https://github.com/JivonKiang/mild-cognitive-impairment

The repository DOI will be added after the immutable `v5.0.0` tag is archived.
Do not invent a DOI or cite the repository as a published clinical validation
study. Update this file and `CITATION.cff` when the final article metadata are
known.

## When citation is expected

Please cite the repository and the relevant original GEO studies when you:

- reuse or adapt code from `code/`;
- reuse aggregate tables from `data/aggregate/`;
- reproduce, extend or publish an analysis based on this release.

The MIT license requires preservation of its copyright and license notices.
The citation request above is an academic attribution request and does not
replace the license terms.
